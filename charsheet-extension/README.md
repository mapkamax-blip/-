# Карточка персонажа — расширение для Owlbear Rodeo

## Что это делает

- **Правый клик на свой токен персонажа → «Показать карточку»** — карточку
  сразу видят ВСЕ подключённые (и ты, и игроки).
- **«Скрыть карточку»** — убирает её у всех.
- **«Изменить карточку»** (только у тебя, ГМа) — открывает форму: имя, раса,
  четыре характеристики (С/Л/У/Ж) и список способностей (по одной в строке).
  Сохранённые данные хранятся прямо в токене персонажа.

Игрок не может ничего редактировать — у него есть только «Показать»/«Скрыть».
Поскольку у тебя включён Owner Only, игрок физически не может выделить
чужой токен, поэтому не сможет показать чужую карточку.

## Как установить (коротко, ты уже проходил это с рюкзаком)

1. Создай в своём репозитории `mapkamax-blip/-` новую папку `charsheet-extension`
   (или отдельный репозиторий — как удобнее) и залей туда все файлы из этого
   архива, сохранив структуру (включая подпапку `icons/`).
2. Если создавал новую папку в уже существующем репозитории с включённым
   Pages — ничего дополнительно включать не нужно, сайт обновится сам.
3. Ссылка на манифест будет:
   ```
   https://mapkamax-blip.github.io/-/charsheet-extension/manifest.json
   ```
4. В Owlbear Rodeo: профиль → Extensions → Add → вставь эту ссылку.
5. Включи расширение для комнаты.

## Важный нюанс (ограничение текущей версии)

Показ карточки работает через мгновенную рассылку (broadcast) — если игрок
обновит страницу или зайдёт в комнату уже ПОСЛЕ того как карточка была
показана, он её не увидит, пока владелец не нажмёт «Показать» ещё раз.
Карточка не "живёт" на сцене постоянно, а всплывает по команде.

## Структура файлов

```
manifest.json      — описание расширения
background.html/js — регистрирует три пункта меню и слушает показ/скрытие
edit.html/js        — форма редактирования карточки (для ГМа)
card-view.html/js/css — сама карточка, которую видят все
icons/              — иконки для контекстного меню
```
