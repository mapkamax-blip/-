# Рюкзак игрока — расширение для Owlbear Rodeo

## Что это делает

- **Правый клик на токен персонажа → «Рюкзак»** — рядом с токеном открывается
  панель со всеми предметами этого персонажа. У каждого предмета есть кнопка
  «Выбросить» — предмет пропадёт из рюкзака и появится токеном на столе рядом
  с персонажем, откуда его сможет подобрать (тем же способом) другой игрок,
  если у него будет доступ к этому токену.
- **Выделить токен предмета + токен персонажа (два токена сразу) → правый
  клик → «Положить в рюкзак»** (только у ГМа) — токен предмета исчезает со
  стола и появляется в рюкзаке персонажа.

Всё состояние живёт прямо в данных сцены Owlbear Rodeo (в metadata токена
персонажа), поэтому синхронизация между тобой и игроками уже встроена —
никакого своего сервера не нужно.

## Как посмотреть локально перед публикацией

Расширение — это просто статические файлы, никакой сборки не требуется.
Например, через Python:

```bash
cd backpack-extension
python3 -m http.server 8080
```

Но просто открыть `localhost` недостаточно — Owlbear Rodeo должен
загрузить `manifest.json` по **публичному https-адресу**. Для быстрой
проверки без выкладывания в интернет можно временно прокинуть порт наружу
(например, через `ngrok http 8080`) и в Owlbear указать выданный ngrok-адрес
+ `/manifest.json`.

## Как выложить насовсем (бесплатно, без своего сервера)

Проще всего — **GitHub Pages**:

1. Создай новый репозиторий на GitHub, например `owlbear-backpack`.
2. Залей в него содержимое папки `backpack-extension` (все файлы из корня).
3. В настройках репозитория → Pages → Source выбери ветку `main` и папку `/root`.
4. Через минуту-две сайт будет доступен по адресу вида
   `https://<твой-логин>.github.io/owlbear-backpack/`.
5. Манифест будет лежать по адресу
   `https://<твой-логин>.github.io/owlbear-backpack/manifest.json`.

## Как установить в Owlbear Rodeo

1. Открой свой профиль в Owlbear Rodeo → раздел **Extensions**.
2. Нажми **Add +**.
3. Вставь ссылку на `manifest.json` (см. выше).
4. Зайди в комнату — расширение должно быть включено для неё (обычно
   спрашивает при создании/редактировании комнаты).

## Известные ограничения текущей версии (то, что можно допилить дальше)

- **Права доступа**: панель «Рюкзак» открывается для любого, кто может
  выделить токен персонажа. Она не проверяет, действительно ли этот игрок —
  владелец токена. Для игры с доверенными людьми (в том числе с детьми) это
  не проблема, но при желании можно добавить проверку через
  `OBR.player.id` и `createdUserId` токена.
- **Передача предмета конкретному игроку** пока не реализована — только
  «выбросить на стол», а другой игрок поднимает его тем же способом (кладёт
  в свой рюкзак через контекстное меню, если у него есть права ГМа, либо
  вариант с прямой передачей можно добавить отдельным пунктом меню).
- **Стопки одинаковых предметов** (например, 5 стрел одной пачкой) сейчас
  хранятся как отдельные записи — если нужно, можно добавить поле
  `count` и объединять одинаковые предметы.
- Размер и якорь (grid/offset) выброшенного предмета берутся из исходного
  токена на момент добавления в рюкзак — если у тебя разные предметы разных
  размеров, это сохранится корректно.

## Структура файлов

```
manifest.json      — описание расширения для Owlbear Rodeo
background.html/js — регистрирует два пункта контекстного меню
inventory.html/js  — сама панель рюкзака (открывается по клику на «Рюкзак»)
style.css          — стили панели
icons/             — иконки для контекстного меню
```
